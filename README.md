视觉模块代码：Cynthia Wang，采用AI辅助开发。机械与电控为团队其他分工，不作为个人独立成果。

## 当前文件

- `code/camera_preview.py`：实时摄像头预览。
- `code/camera_debug.py`：摄像头调试。

## 运行

设备为MaixCAM（非Pro），通过MaixVision连接并在设备上运行代码。代码使用设备端`maix`模块，不能当作普通Windows摄像头程序运行。
预览代码沿用MaixPy官方摄像头示例的基本结构，来源：https://wiki.sipeed.com/maixpy/doc/zh/README_MaixCAM.html 。保留第三方来源，不把示例原理当作原创算法。
